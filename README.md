# ShopEase Android Project

यह पहला native Android prototype है।

## इसमें अभी
- Home screen
- Search
- Products
- Add to Cart
- Cart total
- Responsive native Android UI

## Android Studio में खोलना
1. ZIP extract करें।
2. Android Studio में `ShopEaseAndroid` folder खोलें।
3. Gradle sync होने दें।
4. Android phone में Developer Options + USB debugging चालू करके Run दबाएँ।
5. APK के लिए Build > Build APK(s) चुनें।

अगले development चरण: Firebase product database, OTP login, checkout/address, COD/UPI payment, orders और admin panel.
